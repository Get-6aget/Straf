# ПЕРЕКАТ — арена-шутер для Яндекс Игр

Быстрый шутер от первого лица с короткими раундами против ботов. Стиль, механики и структура повторяют STRAFTAT (подробности — в `docs/research.md`), а весь контент свой. Сейчас это **вертикальный срез v2**: одна карта «Двор», 11 видов оружия, новое движение без перекатов. Текстуры и небо — CC0 с Poly Haven.

## Запуск

```bash
npm install
npm run dev        # локальная разработка
npm run build      # сборка в dist/
npm run zip        # сборка + perekat-yandex.zip для загрузки в консоль Яндекс Игр
```

Сборка использует относительные пути (`base: './'`), а `index.html` лежит в корне архива, как требует Яндекс.

## Яндекс Игры SDK (`src/sdk.js`)

- `/sdk.js` подключается динамически. Вне Яндекса все вызовы становятся заглушками.
- `LoadingAPI.ready()` вызывается после загрузки меню.
- `GameplayAPI.start()/stop()` вызываются при начале и конце игрового процесса, а также на паузе.
- `game_api_pause` / `game_api_resume` и смена видимости вкладки выключают звук и ставят игру на паузу.
- Полноэкранная реклама показывается между матчами, на время показа звук выключается.
- Язык берётся из `environment.i18n.lang` (ru/en). На мобильных включается сенсорное управление.

## Игра

- **Режимы:** 1×1, 2×2, все против всех (4 игрока). Остальные места занимают боты трёх уровней сложности.
- **Структура матча:** тейк выигрывает последний выживший. Раунд забирает тот, кто первым взял 2 тейка. Матч длится до N раундов (2/4/6/8). Каждый раунд — новая карта. Если все погибли с разницей меньше секунды, тейк засчитывается всем.
- **Движение:** бег с сохранением инерции и стрейфом в воздухе, подкат (C на бегу), перекат (Shift), нырок в воздухе с переходом в перекат при приземлении, отскок от стены (прыжок в воздухе у стены, до 3 раз), выглядывание (Q/E), батуты.
- **Анимации:** у ботов от третьего лица — бег, подкат, перекат (кувырок), нырок, отскок от стены, смерть. От первого лица — камера кувыркается при перекате, наклоняется в подкате и при отскоке; вьюмодель качается, даёт отдачу, есть анимации смены оружия, удара и броска.
- **Оружие:** 18 видов плюс кулаки, у каждого своя способность на ПКМ. Оружие одноразовое и лежит на спавнерах. Пустое или любое оружие можно бросить (G): попадание наносит 30 урона и оглушает. Уникальные виды: Гарпун (притягивает к стене или врага к себе), Резонатор (конус отталкивания, умеет сбрасывать в пропасть; отдача-прыжок), Попрыгун (рикошетящие шары), Искра (цепная молния и перегрузка), Липучка (мины с дистанционным подрывом).
- **Киллфид** показывает, кто, чем и как убил: «в голову», «в полёте», «в подкате», «без прицела», «рикошет», «бросок», «в пропасть» (толкнувшему засчитывается фраг) и другие пометки. Также есть самоподрыв и «сорвался в пропасть».
- **20 карт** с пасмурным мягким светом: сильная заливка от неба, слабый рассеянный ключевой свет, мягкие тени, густой цветной туман и постобработка (зерно, виньетка, приглушённая палитра).
- **Музыка** — процедурная электроника (брейкбит, хаус, гэридж, чилл). Каждый раунд генерирует новый трек, в меню звучит спокойный. Все звуки синтезируются в WebAudio, аудиофайлов в сборке нет.

## Структура

| Файл | Что внутри |
| --- | --- |
| `src/fighter.js` | общий контроллер движения игрока и ботов |
| `src/combat.js` | стрельба, снаряды, взрывы, способности, подбор и броски, урон |
| `src/weapons.js` | характеристики и модели оружия |
| `src/maps.js` | 20 карт (DSL из боксов) и палитры |
| `src/scene.js` | меши карты, освещение, туман, небо |
| `src/nav.js`, `src/bot.js` | навигационный граф с A* (шаги, прыжки через пропасти, батуты) и ИИ ботов |
| `src/game.js` | матч, тейки и раунды, камера, спектатор, киллфид |
| `src/viewmodel.js` | оружие от первого лица и постобработка |
| `src/audio.js`, `src/music.js` | синтезированные звуки и музыка |
| `scripts/*.mjs` | проверки в headless Chrome: `sim.mjs` (бой ботов), `shots.mjs` (скриншоты меню, вида от первого лица и поз) |
